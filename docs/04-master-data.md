## 2. 항목 정의

### 2.1 회사정보
화면은 **기본정보**와 **상세정보** 카드 2개로 나눕니다. 수정은 관리자만 할 수 있습니다.

| 구분 | 항목 | 규칙 |
|---|---|---|
| 기본정보 | 상호(필수), 사업자등록번호, 법인등록번호, 대표자, 설립일 | 사업자번호 `000-00-00000`, 법인번호 `000000-0000000` |
| 상세정보 | 우편번호, 기본주소, 상세주소 | **주소 검색**(카카오 우편번호 서비스, API 키 불필요)으로 우편번호·기본주소를 채우고 상세주소만 입력. 우편번호는 숫자 5자리 |
| | 전화번호, 팩스번호, 대표 이메일 | |
| | 회사 CI 이미지 | PNG·JPG·WEBP·SVG 2MB 이하. Storage 공개 버킷 `company-assets`에 저장(업로드·삭제는 관리자만). 저장 시 반영, 바뀐 이전 파일은 자동 정리 |

### 2.2 화주사
| 항목 | 필수 | 규칙 |
|---|---|---|
| 화주코드 | 자동 | **자동채번** `S` + 5자리 (예: `S00001`). 등록할 때 DB 순번으로 부여, 등록 후 변경 불가 |
| 화주명 | ● | |
| 사업자번호 | | 숫자만 입력하면 `000-00-00000`으로 자동 포맷 |
| 주소 | | 우편번호·기본주소는 **주소 검색**(카카오 우편번호 서비스)으로 채우고 상세주소만 입력 |
| 담당자명·연락처·이메일, 비고 | | 업무용 연락처. 연락처는 숫자만 입력하면 자동 포맷 |
| 사용여부 | ● | 미사용 화주는 입고예정 등록 불가 |

> 화주코드 자동채번 전환(마이그레이션 10) 때 기존 화주사는 **등록순으로 `S00001`부터 재채번**했습니다. 다른 테이블은 `shippers.id`로 연결되어 영향이 없지만, 품목 엑셀 일괄등록은 화주코드로 화주사를 찾으므로 예전 양식의 화주코드는 새 코드로 바꿔야 합니다.

### 2.3 센터정보
기본 센터 1개를 초기값으로 만들어 둡니다(코드 `C001`, 명칭 `기본센터`). 화면에서는 명칭·주소·전화만 수정합니다. 다중 센터는 지금 범위 밖이지만, 테이블 구조는 확장할 수 있게 두었습니다.

엑셀 일괄등록 절차는 다음과 같습니다.
1. 양식을 내려받습니다. 열은 화주코드, 화주품목코드, 품명, 규격, 바코드, 단위, 입수량, 로트관리(Y/N), 유통기한관리(Y/N)입니다.
2. 파일을 업로드하면 미리보기에서 행별 검증 결과(오류 사유)를 보여 줍니다.

## 3. 공통코드 초기값

| 유형코드 | 유형명 | 코드 |
|---|---|---|
| UOM | 단위 | EA(낱개), BOX(박스), PLT(팔레트), KG(킬로그램), SET(세트) |
| VEHICLE_TYPE | 차종 | CARGO(카고), WING(윙바디), TOP(탑차), REFRIG(냉장·냉동탑), DAMAS(다마스·라보) |
| INSPECT_RESULT | 검수결과 | NORMAL(정상), QTY_MISMATCH(수량불일치), DAMAGED(파손·오염 반송), WRONG_ITEM(품목불일치 반송) |
| RETURN_REASON | 반송사유 | DAMAGE(파손), CONTAMINATION(오염), WRONG_ITEM(품목 불일치), ETC(기타) |
| USER_ROLE | 사용자권한 | ADMIN(관리자), OPERATOR(운영자), WORKER(작업자), SHIPPER_USER(화주사용자) |

## 4. 권한 매트릭스

| 기준정보 | 내부 관리자 | 내부 운영자·작업자 | 화주 사용자 |
|---|---|---|---|
| 회사정보 | 조회·수정 | 조회 | – |
| 화주사 | 등록·수정 | 조회 | 자기 회사 조회 |
| 센터정보 | 조회·수정 | 조회 | 조회 |
| 품목 | 등록·수정·엑셀·승인 | 조회 (운영자는 승인 가능) | 자기 화주 등록·수정·엑셀 (3PL 승인 필요) |
| 차량 | 등록·수정 | 조회 | 자기 화주 등록·수정 |
| 공통코드 | 등록·수정 | 조회 | 조회 |
| 사용자 | 등록·수정·비밀번호 초기화 | – | – |

**품목 승인 흐름 (3단계 확정)**
- 화주가 등록하면 `승인대기` → 3PL(관리자·운영자)이 승인 또는 반려(사유 필수)합니다.
- 승인된 품목을 화주가 수정하면(품명·규격·바코드·단위·입수량·로트/유통기한 관리·화주품목코드) 다시 `승인대기`가 됩니다. 사용여부 변경은 재승인 대상이 아닙니다.
- **승인된 품목만** 입고예정에 사용할 수 있습니다. 내부 관리자가 등록한 품목은 즉시 승인됩니다.
